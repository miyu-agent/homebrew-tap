# Homebrew tap for Miyu

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is the Homebrew tap for the Miyu family of programs.

It currently has the formula for [LiteMiyu](https://github.com/miyu-agent/litemiyu), which supports macOS on Apple silicon and Homebrew on Linux (x86_64, aarch64). To install it, run:

```bash
brew install miyu-agent/tap/litemiyu
```

The formulas here are updated after every release by this repository's workflow ([`litemiyu.yml`](.github/workflows/litemiyu.yml)); please do not edit them by hand. The workflow takes the template from the program's repository, checks the hashes and the build provenance attestation of the release archives, and commits only after a real install on macOS and on Linux. If you find a problem with a formula, please report it in the repository of the program it installs.
