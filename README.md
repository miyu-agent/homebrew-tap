# homebrew-tap

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 系列程序的 Homebrew 软件源。

配方（formula）会随着 [LiteMiyu](https://github.com/miyu-agent/litemiyu) 的正式版一起加入。加入以后的安装方法是：

```bash
brew install miyu-agent/tap/litemiyu
```

这里的配方由 [miyu-agent/packaging](https://github.com/miyu-agent/packaging) 的工作流在每次发版以后更新，请不要直接修改。发现配方有问题时，请到对应程序的仓库提出。
